# UFO CSV ジェネレーター

音声ファイルを解析して、**Vorze UFO TW / UFO SA** ローター制御用の CSV スクリプトを自動生成する、インストール不要の Web アプリです。スマホ（Android Chrome 等）でそのまま動きます。

## 使い方

1. このリポジトリの `index.html` をスマホのブラウザで開く
   - GitHub Pages を有効化すると `https://<ユーザー名>.github.io/testGame/` で開けます
   - または `index.html` を端末に保存してローカルで開いてもOK（音声はアップロードされません）
2. **音声ファイル**を選択（m4a / mp3 / wav / ogg 等）
3. **デバイス形式**を選ぶ（UFO TW = 2ローター / UFO SA = 1ローター）
4. 必要ならマッピング設定を調整
5. **「解析してCSVを生成」** → プレビュー確認 → **「CSVをダウンロード」**
6. 保存された CSV を Vorze アプリ等に読み込ませる

## 生成される CSV フォーマット

元データを解析して校正したフォーマットに準拠しています。

| 形式 | 列 | 例 |
|------|----|----|
| UFO TW | `時間, 左方向, 左速度, 右方向, 右速度` | `2413,1,15,1,15` |
| UFO SA | `時間, 方向, 速度` | `41,1,10` |

- **時間単位**: 0.1 秒（添付サンプル3ファイルの「最大時間 × 0.1 ≒ 音声尺」で校正）
- **方向**: `0` / `1`（回転方向）
- **速度**: `0`〜`100`（`0` = 停止）
- 値が変化したフレームのみ行を出力（元データと同じ方式）
- 先頭・末尾に停止行（`0,...`）を付加

## マッピングの考え方（コンテンツ連動）

単純な音量トリガーでは「普通の会話」でもローターが動いてしまいます。本アプリは音量だけでなく**音の中身を解析**し、吐息・ささやき・擦過擬音に反応して会話では動かないようにします。

実音声での検証で、声と吐息は音響的に明確に分離できることを確認しました（FFT不要の軽量特徴量で実装）:

| 特徴量 | 声(会話) | 吐息/ささやき |
|---|---|---|
| 周期性(自己相関) | 0.83 | 0.17 |
| 高域エネルギー比 | 0.07 | 0.17 |
| ゼロ交差率 | 0.10 | 0.22 |
| 有声確率(F0) | 0.77 | 0.01 |

- **速度** ← 「刺激エンベロープ」をマッピング。会話（有声・周期的）は抑制し、吐息（無声・高域）を強調
- **回転方向** ← 擦過擬音（かりかり/こりこり等）の反復アクセントで反転
- **UFO TW の2ローター** ← バイノーラル（耳の左右に追従）・ステレオ・帯域分割・ミラーから選択

検証結果（90秒チャンク）: 会話フレームの平均速度31 / 吐息フレームの平均速度62。「抑制」を1.0にすると会話ではほぼ停止します。

### トリガー設定
| 項目 | 効果 |
|------|------|
| 普通の会話の抑制 | 1に近いほど地のセリフで動かなくなる |
| 吐息・ささやき感度 | 吐息/ささやきで動かす強さ |
| 擦過擬音の感度 | 擦過音のアクセントで速度を跳ね上げ＋方向反転 |

### マッピング設定
| 項目 | 効果 |
|------|------|
| 最大速度 | 速度の上限（元データ最大は概ね90） |
| 感度カーブ(γ) | 小さいほど弱い刺激も速度を持ち上げる |
| ダイナミックレンジ | 速度0〜最大に割り当てるdB幅 |
| 無音ゲート | この値未満の速度を0(停止)に |
| なめらかさ | 大きいほど反応が緩やか（隣接フレームへの滲みも増える） |
| 量子化ステップ | 速度の丸め単位 |

### トリガーモード
- **コンテンツ連動**: 上記の中身解析方式（推奨）
- **音量ベース(旧)**: 単純な音量→速度（比較用）

## 今後の拡張（任意）: 意味層（ASR + LLM）

セリフの「意図」（責めゼリフ、擬音の名指し）まで捉えるには、Whisper等で文字起こし→LLMで区間にタグ付けする方法があります。ただし、ささやき/吐息混じりの音声はASR精度が落ち、語の時刻も±0.3秒程度ずれます。また高精度化にはサーバ処理（音声アップロード）が必要です。そのため**正確なタイミングは音響層に任せ、意味層は「責めモード/擬音モードの区間の重み付け」に使う**のが現実的です。必要なら別途追加します。

## 技術メモ

- 完全クライアントサイド（Web Audio API の `decodeAudioData`）。音声は端末外に送信されません。
- 単一ファイル `index.html`（依存ライブラリなし）。
- 対応コーデックは端末・ブラウザ依存。m4a が開けない場合は mp3 / wav をお試しください。

## 注意

これは成人向けデバイス（Vorze UFO）用の制御スクリプト生成ツールです。生成結果は自動解析によるもので、作者が手作業で作り込んだオリジナルとは動きが異なります。設定を調整してお好みに近づけてください。
